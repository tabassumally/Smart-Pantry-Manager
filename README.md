# Smart Pantry Manager

## About the Project

Smart Pantry Manager is an Android application that I am developing for my Mobile App Development 700 practical assignment at Richfield Graduate Institute of Technology.

The idea behind this application is to help people make better use of the ingredients they already have at home instead of allowing leftover food to go to waste. Sometimes we have ingredients in our cupboards or fridge but are unsure what we can prepare with them.

The app will allow users to keep track of their pantry ingredients and find recipes they can make without having to buy anything extra.

## What I Plan to Include

The application will allow users to:

- Add new ingredients and enter their quantities.
- View their current pantry items in a list.
- Edit ingredient details or remove items they no longer have.
- View recipes with their ingredients and preparation steps.
- Get recipe suggestions based only on the ingredients they currently have.
- Save pantry information so that it is still available when they reopen the app.
- Access a settings screen for application preferences.

One of the main features I want to get right is the recipe matching. For example, if a recipe requires five ingredients and the user only has four, that recipe should not appear in the main suggested recipes list. The app must also check whether the user has enough of each ingredient.

## Technologies

The technologies I plan to use for this project are:

- **Java:** To write the Android application.
- **Android Studio:** To develop and test the app.
- **SQLite:** To store pantry items and recipe information locally on the device.
- **GitHub:** To keep track of changes made during development.

## Why I Chose SQLite

I plan to use SQLite because the application mainly needs to store and retrieve information on the user's device. It is suitable for managing pantry items and recipes without needing to set up a separate server or rely on an internet connection for basic database operations.

## Development Progress

I will develop the application in stages, starting with the project setup and basic screens before moving on to the database, pantry management and recipe-matching functionality. I will test the features as I implement them and update this README as the project develops.
